## 一句话定位

> 单机为主、任务制、最多 4 人、房主即服务器，带 RO 式纸娃娃养成与早期 PSP《怪物猎人》式狩猎循环的 Android 掌机 ARPG。

## 后续讨论 Agenda

按优先级排列，每次讨论一个主题，结论回填到对应文件：

1. **战斗手感** —— 直接决定模拟层的 tick 设计与动画状态机
2. **角色成长曲线** —— 等级 / 技能树 / 装备驱动，决定数值结构
3. **任务与副本结构** —— 一局多长、几个阶段、失败与结算规则
4. **城镇形态** —— 决定是否需要额外的多人场景
5. **怪物与 AI 行为** —— 决定模拟层的复杂度上限
6. **美术锚点** —— 定死一套视觉规格，避免资产风格漂移
7. **阶段 0 技术验证的验收标准** —— 见 002 末尾

## 已确认的外部约束

- 开发者是传统程序员，无游戏开发经验，无 2D 手绘能力
- 不打算长期运维服务器，不做官方托管
- 目标设备：Ayn Odin 3（Snapdragon 8 Gen 2 / 1080p 16:9 OLED / 约 8000mAh）
- 操作方式：掌机摇杆 + 按键，同时保留触摸屏
- 16:9 横屏
